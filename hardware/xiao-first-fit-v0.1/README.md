# XIAO first-fit protective holders v0.1

2026-10-01．ヘッダーなしの4台に向けた，無通電での初回フィット確認用です．

- XIAO ESP32S3 Sense ×1
- XIAO nRF52840 Sense ×2（同じハードウェア版を想定）
- XIAO RA4M1 ×1

## 状態と制限

ケース，カラー，共通フット，トレーはオリジナル設計です．基板裏面と側面を保護する開放型の卓上ホルダーで，完全密閉ケースではありません．基板，カラー，ホルダーは重力で載せるだけで，ラッチはありません．上下反転，持ち運び，USBケーブルで吊るす用途には使わないでください．上面とUSB開口から細い金属物が入る可能性があります．

現物の寸法，はんだ，USBケーブル，カメラ型番，ヒートシンク，無線／音響性能，印刷精度，保持力，温度は未検証です．まずUSBと全電源を外して，冷めた基板で寸法を確認してください．PLA試作は無通電のフィット確認用です．防水，難燃，完全絶縁，ESD保護の認証はありません．

ESP32S3 Senseの[公式WebCamera試験](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/#installing-the-upgraded-heat-sink)では，室温約27°Cで1時間動かした背面熱パッドがヒートシンクなしで63.6°Cに達しています．本設計の開放上面や下面すき間は冷却保証ではありません．連続撮影用には，実物のヒートシンク，材質，通風，温度を確認して次版へ進めます．

## ファイル

- `sources/build_physicalci.FCMacro`：編集可能なFreeCAD生成ソース
- `freecad/`：オリジナル部品のネイティブ文書と公称PCB箱だけの組立表示
- `step/`：CADソリッドから直接書き出した解析曲面STEP
- `stl/`：印刷方向に配置済みの8種類のSTL
- `PARAMETERS.json`：主要寸法と印刷個数の一覧（生成コードの入力ではありません）
- `reports/`：この公開パッケージのデジタル検証結果
- `SOURCES.json`：公式参照の取得先，SHA-256，版の注意
- `MANIFEST.json`：公開パッケージのファイルとSHA-256

この公開版にはSeeedのSTEP，DXF，PCB，それらを埋め込んだFCStdや画像を含めません．公式参照データの再配布条件は未確定です．生成ソースはそれらを必要とせず，公称PCB箱だけで組立を表示します．カメラや部品の詳細を表示するモデルではありません．リポジトリ全体のライセンス未選択状態は変更していません．

## 寸法と保持

- 公称PCB外形：17.8 × 21.0 mm，片側すき間0.50 mm
- 壁：1.6 mm，床：2.4 mm，PCB下面までの空間：3.2 mm
- 支持レール：幅1.6 × 長さ15.0 mm（裏面部品との接触を実物で確認）
- 上が開いたUSB切欠き幅：14.6 mm（実プラグ未測定）
- 共通フット：36 × 36 mm，角R3
- トレーポケット：36.8 × 36.8 mm，中心間隔40.8 mm
- トレー全体：165.6 × 52.8 × 5.2 mm
- カラー片側すき間：0.35 mm，重なり：3.2 mm
- ガード高さ：nRF 8.8 mm，RA4M1 9.2 mm，ESP 9.6 mm

トレー前方の3.2 × 6.4 mmスロットは，USBケーブルの外被を柔らかいストラップで留めるためのアンカーです．ストラップは別途必要で，引張保持は未検証です．基板や金属コネクタを縛らず，USB付近に余長を取り，ストラップの頭が底面を持ち上げないようにしてください．抜き差し時は基板とホルダーを支えてください．

カラーは側壁に着座し，基板やカメラへ荷重をかけない想定です．部品やはんだに当たる場合は押し込まず寸法を調整します．ESPのアンテナ線は後ろ上部の切欠きまたは上へ逃がし，SDカード交換時はカラーを外します．装着状態の交換性は未検証です．この36 mmインターフェースはGridfinity互換ではありません．

## 再生成と編集

FreeCAD 1.0.0で確認しました．外部アドオンや公式ボードモデルは不要です．元の配布データを保持するため，既定の出力先はこのディレクトリ内の無視対象`build/`です．

1. FreeCADで`sources/build_physicalci.FCMacro`を開き，マクロとして実行します．またはFreeCADをimportできるPython環境で次を実行します．
2. `build/freecad/`の各部品で`Parameters`のDataを編集し，再計算します．標準Box／Cylinder／Fuse／Cutと式で構成されています．レビュー組立はスナップショットで，自動追従しません．
3. 変更後は再エクスポートし，メッシュとCADを再検証してください．生成コードを変更した場合はコードと出力を同じPRで更新します．

```bash
# このディレクトリから実行．PythonがFreeCAD，Part，MeshPartをimportできることが前提．
python3 sources/build_physicalci.FCMacro
python3 sources/validate_meshes.py --root build
python3 sources/verify_cad.py --root build
```

LinuxのFreeCADパッケージでは，ライブラリ位置に応じて`PYTHONPATH=/usr/lib/freecad/lib /usr/bin/python3 ...`が必要な場合があります．出力先は`PHYSICALCI_OUTPUT_ROOT`環境変数またはマクロ実行時の`OUTPUT_ROOT`で変更できます．生成処理は既存のGUI文書を閉じず，ネットワーク，USB，プリンタを操作しません．

## デジタル検証

公開ソースから別の出力先へGUIなしで再生成しました．8種類のSTLは初回配布STLとバイト単位で一致しました．

- 全8STL：閉じた単一連結メッシュ，正の体積，境界／非多様体／方向不整合エッジ0，ゼロ面積三角形0，Z=0
- 8印刷部品：有効な閉ソリッド各1個
- 11STEP：再読込で有効，印刷部品は1ソリッド，組立は2ソリッド，平面／円筒面を維持
- nRFのXYClearance 0.50→0.65で体積変化を確認し，復帰後の元体積とSTEP体積の一致を確認
- `python3 -m unittest discover -s tests -v`でアーティファクト整合性も確認

三角形同士の全組合せ自己交差検査，実物フィット，印刷，挿抜，保持，落下，熱，電気的絶縁，無線，音響試験は未実施です．デジタル形状の合格は現物適合の保証ではありません．
