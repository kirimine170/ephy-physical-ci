# 合成U字フレームのコンプライアンス比較

後端を固定する仮定が，フレーム全体の変形をどれだけ隠すかを調べる小荷重・線形FEMの教材である．独自寸法の箱3個からU字形状を生成する．製品のCAD，製品固有寸法，写真，実製品の解析結果は含まない．

**合格は合成モデル内の数値検証の合格であり，現物の保持力・抜ける力・安全性の予測ではない．** 材料は未校正で，接触，摩擦，印刷ビード，層間接合，破壊はモデル化していない．

## 必要な実行環境

- Python 3.10以上．Python部分は標準ライブラリのみを使用する．
- Gmsh CLIとCalculiX CLIをあらかじめ利用可能にしておく．スクリプトはダウンロードやインストールを行わず，binaryも同梱しない．
- solverの共有ライブラリや，Pythonラッパー型Gmshの依存関係は，利用者側で設定した実行環境を継承する．
- 同梱例の実行版は **Gmsh backend 4.13.1，CalculiX 2.23，Python 3.12.14** である．版情報はPython package名から推定せず，各CLIへ照会して記録する．

リポジトリのrootから実行する．既存コマンドがPATHにある場合：

```sh
OMP_NUM_THREADS=1 CCX_NPROC_RESULTS=1 \
python3 experiments/mechanical-ci/frame-compliance/run_experiment.py \
  --gmsh gmsh --ccx ccx \
  --output experiments/mechanical-ci/frame-compliance/output
```

PATHにない場合は，`--gmsh /path/to/gmsh --ccx /path/to/ccx` のように指定する．入力形状の取り込み，外部通信，GUI操作は行わない．`output/` はGit対象外である．`--output`には存在しない新規ディレクトリを指定する．既存ディレクトリやsymlinkは拒否し，古いメッシュ／solver結果を再利用しない．再実行するときは，例として`output/run-2`のような新しい名前を指定する．

```sh
python3 -m unittest discover \
  -s experiments/mechanical-ci/frame-compliance/tests -v
```

この軽量テストは外部solverを起動しない．geometry，荷重，境界条件，parser，数値チェックの部品を検証する．外部solverの実行実績は，別の統合CLI実行とそのJSONで示す．

## 合成モデルと単位

- N，mm，MPaを一貫して用いる．
- 外幅42 mm，長さ58 mm，レール幅3.2 mm，厚さ4.5 mmの合成U字フレーム．両側レールを後端の横棒でつなぐ．前側はy=0，後側はy=58である．
- 基準材は等方・線形弾性，E=1500 MPa，ν=0.30という**未校正の仮定**である．
- 左右の前端面に，X方向外向きの力を **各0.005 N** 加える．力の大きさの合計は0.010 Nで，ベクトル和と総モーメントはゼロになる．
- 前端面はy=0の面であり，ここへX方向の一様な**接線方向荷重**を加える．接触圧力や実際のラッチ荷重ではない．
- 面はtag番号ではなく，全節点のy座標と左右の符号で選び，面積がレール幅×厚さに一致することを検証する．
- 三角形6節点要素へ一様荷重を整合的に積分する．各辺中点の積分重みは面積/3，各頂点は0となり，合力と作用点を保存する．
- 二次四面体C3D10を使用する．GmshとAbaqusの末尾2節点の順序差を変換し，辺中点座標も検証する．

表示するコンプライアンスは「左右の荷重面間距離の変化 / **片側の力**」である．例えば12.8 mm/Nを，1 Nを実際にかけた大変形の予測として使ってはいけない．実際の解析荷重と変位もJSONへ別項目として記録する．

## 2種類の境界条件

`free_gauge` は，自己釣合い荷重を受けるU字フレームから剛体移動だけを除く．

- A=(-21，58，0)でXYZを拘束する．
- B=(21，58，0)でYZを拘束する．
- C=(-17.8，54.8，0)でZを拘束する．
- 合計6自由度のみを拘束し，それぞれの反力が片側荷重の1e-6未満か検証する．

`rear_clamp` はy≥54.8にある全節点のXYZを拘束する．後端横棒と後端側レールを人工的に硬く支える比較条件であり，現実の取付条件とは主張しない．この拘束領域の離散化もメッシュ依存性に含まれる．

**gauge位置を変更した場合の不変性テストは未実装**である．今回の確認は，記載した3-2-1配置の個別反力，力・モーメント釣合い，3メッシュ比較に限定する．

## 実行済みの合成結果

`compact_summary.json` は上記の独自合成モデルを実際に解いたcompactな結果である．raw solver出力や製品データは含まない．

| 最大メッシュ寸法 mm | 二次節点数 | C3D10要素数 | 自由フレーム mm/N | 後端固定 mm/N |
|---:|---:|---:|---:|---:|
| 3.2 | 2187 | 942 | 12.7341 | 5.9679 |
| 2.1 | 4265 | 1903 | 12.6985 | 5.9594 |
| 1.4 | 10327 | 5157 | 12.8163 | 5.9736 |

最細メッシュで，**各0.005 N**を与えた距離変化は，自由フレーム0.064081 mm，後端固定0.029868 mmだった．この合成モデルでは自由フレームのコンプライアンスが約2.145倍となる．この比率を別の形状へ移し替えてはいけない．

中→細メッシュの相対変化は，自由フレーム0.919%，後端固定0.238%で，設定した2%未満の判定に合格した．粗い値から単調に近づくとは仮定しない．Eを半分にした追加ケースのコンプライアンス比は約2.000となった．形状を変えた結果，実測値への一致，破壊，疲労の検証ではない．

## 実装したチェックと，未確認の範囲

統合CLIは次を検証し，失敗時は非ゼロで終了する．

- 正の四面体体積とJacobians，二次要素の中間節点位置，解析形状との総体積一致
- メッシュ品質のmean-ratio値を記録する．値だけで応力精度を保証する閾値とは扱わない．
- 2面の面積，荷重の合力とモーメント，外力と拘束反力の釣合い
- 自由フレームの各gauge反力が実質的にゼロであること
- 少なくとも2段階のメッシュ細分化と，最後の2段階のコンプライアンス変化．既定では3段階を実行する．
- E半減時のコンプライアンス2倍，人工的後端固定との大小関係，solver警告の有無

釣合いの許容値は，力が片側荷重×1e-4，モーメントが片側荷重×フレーム長×1e-4である．gauge反力の許容値は片側荷重×1e-6である．絶対値はケースごとにJSONへ記録する．

`validation_scope` は範囲別に`pass`，`fail`，`unknown`を記録する．材料校正，物理接触・摩擦，現物保持力は常に`unknown`であり，数値チェックの`pass`で上書きしない．数値solve以前に起きたCLI／入力エラーは終了コード2で示し，完了したsummaryが存在するとは限らない．

応力ピーク，座屈，大変形，接触，摩擦，嵌合公差，基板や台座，印刷ビード，層間接合，異方性，塑性，クリープ，実際の保持力は未検証である．用途は境界条件への感度を可視化し，何を検証できたかを小さく再現可能な単位で保存することに限る．

## 出力と公開対象

- `output/summary.json`：詳細な合成チェック結果
- `output/compact_summary.json`：持ち運び用の範囲限定JSON．コマンド，実行環境の絶対path，raw節点変位を含めない．
- `output/mesh_*/`：再実行確認用の合成GEO，メッシュ，入力deck，solverログ／結果．公開対象外．
- `compact_summary.json`：確認済みcompact JSONの例．generator・合成GEO・合成mesh・入力deckのSHA-256を含み，再実行時の照合に使える．異なるsolver版やメッシュ生成条件ではhashや細部の数値が変わり得る．

全体の数値的`checks_passed`がtrueでも，物理的な合否が確定したことにはならない．
